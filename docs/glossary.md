# Glossario

| Termo | Definicao |
| --- | --- |
| Antecipação | Pagamento realizado antes do vencimento esperado de uma parcela ou contrato. |
| BNDES FINAME SELIC | Tipo de contrato cujá projeção utiliza Selic e dias úteis. |
| BNDES FINAME TFC | Tipo de contrato cujá projeção utiliza a regra TFC e dias corridos. |
| Bem | Ativo cadastrado e vinculado a fornecedor e contrato. |
| Carencia | Periodo inicial do contrato antes da amortização do principal. |
| Chassi | Identificação de um bem veicular, armazenada em `bem`. |
| Contrato | Operação de financiamento administrada pelo sistema. |
| Data BNDES | Data utilizada como referencia para localizar a Selic do contrato. |
| Data de referencia | Data derivada da emissão e utilizada no cálculo das parcelas. |
| Dia util | Dia que não e fim de semana nem feriado cadastrado. |
| Feriado | Data que deve ser excluida do calendário de dias úteis. |
| Liquidação | Quitação total ou parcial registrada para um contrato. |
| Matérialized view | Resultado persistido de uma consulta que precisa ser atualizado por refresh. |
| Pos-fixado | Modalidade cujá atualização depende de um indexador, como Selic. |
| Projeção | Calculo futuro de parcelas, juros, saldo e vencimentos. |
| Selic | Taxa armazenada por data e utilizada nos cálculos aplicaveis. |
| TFC | Modalidade de cálculo utilizada pelo tipo BNDES FINAME TFC. |
| Veiculo | Associação de bens de chassi e carroceria na estrutura do banco. |
