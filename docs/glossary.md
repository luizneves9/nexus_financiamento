# Glossario

| Termo | Definicao |
| --- | --- |
| Antecipacao | Pagamento realizado antes do vencimento esperado de uma parcela ou contrato. |
| BNDES FINAME SELIC | Tipo de contrato cuja projecao utiliza Selic e dias uteis. |
| BNDES FINAME TFC | Tipo de contrato cuja projecao utiliza a regra TFC e dias corridos. |
| Bem | Ativo cadastrado e vinculado a fornecedor e contrato. |
| Carencia | Periodo inicial do contrato antes da amortizacao do principal. |
| Chassi | Identificacao de um bem veicular, armazenada em `bem`. |
| Contrato | Operacao de financiamento administrada pelo sistema. |
| Data BNDES | Data utilizada como referencia para localizar a Selic do contrato. |
| Data de referencia | Data derivada da emissao e utilizada no calculo das parcelas. |
| Dia util | Dia que nao e fim de semana nem feriado cadastrado. |
| Feriado | Data que deve ser excluida do calendario de dias uteis. |
| Liquidacao | Quitacao total ou parcial registrada para um contrato. |
| Materialized view | Resultado persistido de uma consulta que precisa ser atualizado por refresh. |
| Pos-fixado | Modalidade cuja atualizacao depende de um indexador, como Selic. |
| Projecao | Calculo futuro de parcelas, juros, saldo e vencimentos. |
| Selic | Taxa armazenada por data e utilizada nos calculos aplicaveis. |
| TFC | Modalidade de calculo utilizada pelo tipo BNDES FINAME TFC. |
| Veiculo | Associacao de bens de chassi e carroceria na estrutura do banco. |
